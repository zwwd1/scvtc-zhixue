## 课间使用

1. 设置 → 成绩与学分。已经保存的成绩可离线查看。
2. “成绩”中选择全部或一个学校学期，输入课程名称或代码，按学校顺序、成绩或学分排列。
3. 汇总统计对应完整学期，搜索仅缩小明细。点成绩卡片查看完整字段，再点收起。
4. “学分”显示成绩中已确认获得、学校毕业学分要求和数值差额。点击学期行返回该学期成绩。
5. 刷新仅更新学校查询缓存，不修改手工课表。若学校要求额外认证，使用“补充学校认证”。

## 知学使用

1. 首页“成绩与考试”与服务中心“成绩查询”进入同一页面。
2. 在学期或总体页查找课程、选择课程性质和排序。右上角导出包含当前筛选后的记录；汇总仍表示完整范围。
3. 刷新过程中继续查看旧记录；失败后查看提示并重试，离线记录不会被清空。
4. 服务中心 → 学分概况，比较确认所得与学校要求，或打开学校官方页面。学分达标不等于毕业审核通过。
5. 教务同步 → 刷新课表。离开页面后同步任务继续；系统后台限制仍可能影响持续运行。
6. AI 配置 HTTPS 服务、模型与密钥。失败或停止后用“重试上一条”；仅在明确开启课表授权时发送课表上下文。账号退出与清除 AI 对话分别需要确认。

## 设计依据

- [Android 导航原则](https://developer.android.com/guide/navigation/principles)：固定主入口，子页回到实际来源，避免同一任务出现互不一致的流程。
- [Android 布局与导航模式](https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns)：主导航与页内筛选分别承担稳定入口和局部操作。
- [Compose 状态保存](https://developer.android.com/develop/ui/compose/state-saving)：保存筛选、排序和输入草稿，数据缓存继续使用现有持久化层。
- [Compose 可访问性默认行为](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)：使用原生控件及有操作语义的可点击区域，避免只有图形而没有操作名称。

仅根据实际接口和代码修改流程；没有添加模拟成绩、演示课表、抓取诊断文件或自动化测试代码。
