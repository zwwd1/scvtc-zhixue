# 安装与使用

1. 从本项目取得 APK，核对版本、SHA-256 和验证报告。
2. 已安装本项目时直接覆盖安装，保留应用数据。不要先卸载；卸载会删除本机密钥和登录记录。
3. 在应用登录页填写学号和学校密码，点击“登录并自动同步”。学校认证和教务会话建立由应用在后台完成。
4. 学生身份核验通过后即可进入首页；课表、成绩和考试继续在后台读取，进度和成功时间显示在首页。核对账号、学期、首周日期和课程。
5. 服务中心只显示课表、成绩和学分；考试、通知、请假等使用下方“学校官方教务系统”。

登录成功后，凭据加密保存在当前安装。再次打开优先使用已有 Session，会话失效后自动尝试恢复并继续同步。离开登录页或切换页面不会取消正在运行的应用任务；切换账号保留各自的加密凭据。学校额外验证时使用“补充认证”；密码变更、网络不可达或系统限制后台执行时，保留离线内容并显示未完成的操作。

## 日常操作

- 课表支持日/周查看，原生编辑、导入导出、提醒和桌面组件继续可用。
- 当前教学周依赖校历首周日期。日期未核实前先检查设置，不能把今天直接当第一周。
- 成绩读取完整分页，按学校实际学期筛选；官方确认的空记录与请求失败分别显示。
- 学分页分别显示官方毕业要求、成绩所得和计算口径。重修按课程代码合并；未知字段不作为零值，不能据此判断毕业资格。
- 学校官网保留服务办理、我的查询、毕业论文与学籍管理；App 提供返回、官网首页、刷新、重新认证、系统浏览器和全屏入口，真实新窗口可关闭。提交、报名和资料变更由本人确认。
- 课表右上角液态玻璃刷新按钮复用已保存认证；同步中禁用重复点击。只有成功保存后才更新成功时间。
- 壁纸可调焦点与缩放；课程卡片的模糊、高光、圆角和透明度独立调整。
- 小澄有微笑、侧目、眨眼、思考和点击回应；设置 → 外观 → 卡片与动效中可隐藏、缩放并预览，后台暂停循环。
- 未接入模块可使用官方入口；报名、评教、请假和资料修改由本人确认。
- 云服务暂停，本机同步直接连接学校。更换手机后首次登录不能依靠复制旧密文完成。

## 自己调节效果

设置 → 外观是唯一外观入口。液态玻璃开启时保留完整折射、色散与跟随动效；关闭时统一使用高斯模糊，包括底栏和弹出菜单。卡片与动效中显示实际机型，模糊、高光、圆角、透明度、按压动效和减少动态效果可自行调整、恢复默认。默认使用完整渲染，不根据机型自动降低效果。自定义壁纸和已有课程记录继续保留。

同页的“底栏玻璃与回弹”提供实际原生底栏的模糊、折射、色散、高光、投影和弹簧力度。默认保持原版配方，恢复按钮同时恢复轨道与选中透镜的原始默认值；关闭液态玻璃后，折射与色散参数暂不启用。

## AI 助手

课程首页 → AI 助手，首次配置自己使用的 HTTPS Chat Completions 服务地址、模型和 API Key。应用没有内置公共 Key，也不会用学校密码调用 AI。设置和对话按当前账号加密保存在本机。

“附带课程信息”默认关闭。开启后仅附带课程名称、地点、节次、星期和周次，不附带学号、学校密码、Cookie 或成绩。请求直接访问用户配置的服务，隐私政策由该服务决定。发送中可停止，清空仅删除当前账号的 AI 对话。

## 排查问题

| 现象 | 处理 |
| --- | --- |
| 认证未完成 | 检查学校网络和账号密码；确有验证码时使用补充认证，保留旧课表 |
| 账号不一致 | 回到自己的学校账号，避免将其他人的 Session 写入当前缓存 |
| 有课表没有成绩 | 单独刷新成绩，区分官方空结果与接口请求失败 |
| 后台没有及时更新 | 检查系统后台和联网权限；任务实际执行时间由系统调度 |
| 升级后需登录 | 检查是否卸载、清数据、换手机，或学校已经使凭据失效 |
| 需要备份 | 使用明确的本地导出入口；导出文件可能含课程信息，登录凭据不随普通备份迁移 |
