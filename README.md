# 川职·知学

知学把四川职业技术学院的课程和教务记录放在一个 Android 应用里：首页看今天上什么课，课表看整周安排，成绩和学分单独查看，其他业务进入学校官网办理。

它以 zhengfang-apk 为基础重构，保留原生课程页面和完整玻璃动效，加入川职专用的登录、同步和服务入口。项目由 [zwwd1](https://github.com/zwwd1) 维护，非学校官方应用。

知学保留了原项目的浏览器和扩展运行环境，安装包会比课间大。两版都开源，学校记录均以教务系统为准。

## 安装后怎么用

需要 Android 13 或以上版本。首次安装且没有数据时，先连接川职教务：填学校统一认证的学号和密码，点击“登录并自动同步”。已有数据的覆盖安装直接进入应用。

身份核验成功后即可看课表，同步继续在后台进行。会话过期时会尝试重新认证；只有学校出现额外验证时，才需要进入学校认证页完成。密码变更后更新本机保存的密码。

首页显示今日课程和同步进度。点课程看详情，进入课表切换日周视图。成绩支持学期切换、搜索、筛选和导出，学分页可跳到对应的课程记录。服务中心只保留已接通的功能；请假、学籍等业务通过学校官方教务入口办理。

“当前课表详情设置”统一管理开学日期、节次时间、课前提醒、小组件和自定义课程。周末显示、字号、节次高度和时间列也在这里调整，修改显示不会改变课程或提醒记录。

壁纸、按钮和底栏共用外观设置。液态玻璃关闭后统一使用高斯模糊，底栏的原有动效与可调参数保留。AI 助手需要配置自己的模型服务，看板娘“小澄”有不同待机与交互状态。

## 它是怎样实现的

`cn/scvtc/campus` 负责学校认证与接口，`com/tyust/course/scvtc` 负责本机同步和川职页面，`school-core` 负责课程、日期与解析规则。

应用在后台打开学校认证流程，取得教务会话，再用学生身份接口核对账号。网页地址跳转本身不算登录成功。课表和教务记录从真实接口读取，按账号与学期保存在本机，再交给原生页面展示。

刷新失败保留上次数据和成功时间。手动课程、课程编辑与提醒有各自的存储，不会因一次学校请求失败被删除。学校没有返回的毕业要求不会补成一个假进度。

密码、会话和服务缓存使用 Android Keystore 与 AES-GCM 按账号加密。普通导出不含登录凭据，云服务和匿名统计保持暂停。AI 的密钥和对话在本机加密保存；课程授权默认关闭，开启后才向你配置的服务发送课程上下文。

## 自行构建

使用 JDK 21、Android SDK 37.0 和仓库里的 Gradle Wrapper：

```powershell
.\gradlew.bat :app:assembleRelease
```

签名配置放在仓库之外。本项目正式更新沿用第一版的包名和签名；自行签名的 APK 不能直接覆盖正式版。插件契约、SDK 与审核工具链保留一致性检查。

正式包、源码标签和 SHA-256 随 [GitHub Release](https://github.com/zwwd1/scvtc-zhixue/releases) 一起发布。[验证报告](VERIFICATION.md) 会区分构建检查和实机体验，不把未执行的登录或性能验证写成通过。
