# 川职·知学 1.2.3

这次把连接教务和课表设置收进统一流程，替换之前厚重的双层按钮边框。

- 新安装且没有本机数据时先连接川职账号，登录页只保留学号、密码和学校认证入口。
- 刷新、主题、返回、提醒和同步按钮复用原有玻璃组件，保留折射、按压和底栏动效。
- 设置加入「当前课表详情设置」；字号、节次高度、周末与时间列集中调整，可以恢复显示默认值。
- 节次时间的「未设置」改为红色玻璃按钮，点击继续使用原生时间选择器。
- 二级页支持预测性返回；到达页面顶端后下拉可以返回，后方页面联动模糊。
- 日夜主题与预设壁纸一起过渡，自选图片继续保留自己的色彩和对比度。
- 普通学校弹窗不再当作验证码，表单未就绪、回调超时和补充认证分别提示。
- 项目首页重写，说明知学与课间的区别、操作和实现方式。

直接覆盖安装即可，原签名、已有课程和提醒保留，云服务继续暂停。

本轮不连接手机，不运行功能或性能测试。正式构建、签名和发布检查见验证报告；学校登录、自然过期恢复及手势体验由用户验收。
